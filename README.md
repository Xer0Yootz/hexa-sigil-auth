# Hexa Sigil Auth

Full-stack auth with GitHub repo integration.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Open http://localhost:3000

## Features

- Email/password signup & login
- Google & GitHub OAuth
- GitHub repository browser
- SQLite database
- Neon cyberpunk UI

## Replit

Run: `npm run dev`
