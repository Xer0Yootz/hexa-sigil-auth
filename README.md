# Hexa Sigil Auth

Neon Vigil gateway. Sign in, forge an operative, pass the transition, talk to Hexa.

Imported from the Base44 public source export on 2026-10-04. UI, routing, particles, and Cast sender are plain React. Auth, Character, BitChat, InvokeLLM, and GenerateSpeech still call Base44.

## Run

```bash
cp .env.example .env.local
npm install
npm run dev
```

The shell renders without credentials. Sign-in, saves, replies, and voice need a Base44 app id or a swapped backend.
